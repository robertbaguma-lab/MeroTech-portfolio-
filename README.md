# MeroTech Portfolio + Malippo Landing Page

**Live Site:** [mero-technology.netlify.app](https://mero-technology.netlify.app)

### 🚀 What This Is
Responsive business portfolio + product landing page built from scratch in 21 days. 
No templates, no frameworks. Pure HTML5, CSS3, Vanilla JS.

### 🛠 Built With
- **HTML5** - Semantic markup, SEO optimized
- **CSS3** - Flexbox, Grid, Custom animations 
- **JavaScript** - Mobile nav, form validation
- **Netlify** - CI/CD deployment

### 📱 Features
- **Mobile-first responsive** - Works on 3G ZTE Blade to desktop
- **5-page portfolio** - Home, About, Services, Portfolio, Contact  
- **Malippo product page** - High-converting landing page with testimonials
- **Performance** - 95+ Lighthouse score, <2s load on 3G
